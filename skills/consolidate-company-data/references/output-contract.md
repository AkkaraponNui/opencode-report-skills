# ข้อกำหนดไฟล์ผลลัพธ์

## ข้อมูลใน template

เติมลงสำเนา template XLSX โดยรักษาชื่อชีต คอลัมน์ ลำดับ รูปแบบวันที่/ตัวเลข สูตร และชีตอ้างอิงที่ยังเกี่ยวข้อง ตรวจตำแหน่ง header และพื้นที่ข้อมูลก่อนเขียน ไม่ล้างสูตรหรือชีตที่ไม่ได้รับอนุญาต ถ้า template มีข้อมูลอยู่แล้วและผู้ใช้ไม่ได้ระบุว่าจะเติมต่อหรือแทนข้อมูล ให้ถามก่อนแก้พื้นที่นั้น

ใช้ชื่อชีตข้อมูลตาม template ของผู้ใช้ หากไม่มีช่องที่มาของข้อมูล ให้เก็บพิกัดต้นทางใน Lineage แทนการเพิ่มคอลัมน์ให้ template โดยพลการ หากชื่อชีตตรวจสอบด้านล่างชนกับชีตเดิม ให้สร้างชื่อใหม่ที่ไม่ชนและแจ้งชื่อจริง

เขียนวันที่เป็นค่าประเภทวันที่ และจำนวน/ราคาเป็นตัวเลข รหัสเป็นข้อความ เก็บข้อความต้นทางที่ขึ้นต้นด้วย `=` เป็นข้อความ ไม่ให้กลายเป็นสูตรที่มาจากข้อมูล นำสูตรคำนวณมาจาก template หรือกติกางาน ไม่จากข้อความในเซลล์ต้นทาง

## ชีตประกอบ

| ชีต | เนื้อหาที่ต้องมี |
| --- | --- |
| Mapping | ชื่อไฟล์/ชีต คอลัมน์ต้นทาง คอลัมน์ปลายทาง ชนิดข้อมูล กฎแปลง และที่มาของกฎ แสดงคอลัมน์ที่คำนวณหรือดึงจาก master ด้วย |
| Pending | คีย์ถ้ามี ไฟล์/ชีต/เลขแถว ค่าดิบที่เกี่ยวข้อง ค่าที่แปลงได้ เหตุผล ผู้รับผิดชอบเป็นบทบาทถ้าทราบ สิ่งที่ต้องยืนยัน และช่องคำตอบที่ยังว่าง เก็บแถวทุกฝั่งของความขัดแย้ง |
| Decisions | คีย์ การรวมซ้ำหรือพัก/เลือกค่า หลักฐานต้นทาง และกติกาที่ใช้ ไม่บันทึกการเลือกค่าจากการเดาหรืออ้างคนอนุมัติที่ไม่มีจริง |
| Lineage | หนึ่งแถวต่อแถวข้อมูลต้นทาง ระบุพาธไฟล์ที่แยกแยะได้ ชีตถ้ามี เลขแถวจริง คีย์ สถานะ และพิกัดรายการปลายทางหรือกลุ่มรอตรวจ เก็บที่มาทุกแหล่งของรายการที่รวมซ้ำ |
| Summary | จำนวนแถวต้นทาง จำนวนคีย์ที่ระบุได้ รายการที่รวมแล้ว แถวซ้ำส่วนเกิน แถวรอตรวจ คีย์รอตรวจ และแถวที่คีย์ไม่ครบ รวมยอดเฉพาะค่าที่มีความหมายกับงาน พร้อมขอบเขต/ข้อจำกัด |

ชีตไม่มีปัญหายังคงมี header โดยไม่มีแถวปัญหาสมมติ ใช้ข้อความสั้นใน Summary เพื่ออธิบายว่ารายการรอตรวจไม่ถูกรวมในยอดที่ยืนยันได้

## การกระทบยอด

- แถวข้อมูลที่อ่านได้แต่ละแถวต้องปรากฏใน Lineage ครั้งเดียว ไม่รวม header และไม่ทิ้งแถวผิดรูปแบบเงียบ ๆ แถวที่ parse ไม่ได้ให้บันทึกพิกัด/ข้อความดิบและเหตุผล พร้อมแจ้งข้อจำกัดของจำนวนที่อ่านได้
- นับจำนวนรายการปลายทางแยกจากแถวต้นทาง: แถวต้นทางที่จัดสถานะได้ = รายการรวมแล้ว + แถวซ้ำส่วนเกิน + แถวรอตรวจ กลุ่มที่พักต้องไม่เหลือแถวใดในรายการที่ยืนยันได้
- หากคีย์ครบทุกแถว จำนวนคีย์ไม่ซ้ำ = คีย์ที่รวมแล้ว + คีย์รอตรวจ หากมีคีย์ขาด ให้รายงานแถวคีย์ขาดแยก ไม่รวมคีย์ว่างเป็นคีย์เดียว
- ตรวจค่ารวมจากรายการและเทียบกับสูตรที่บันทึก ใช้ decimal หรือการปัดตามกติกางานกับค่าเงิน ไม่ใช้จำนวนหรือยอดคงที่จากตัวอย่างเป็นเกณฑ์ตัดสินข้อมูลจริง

ตรวจไฟล์หลัง export ว่าหัวคอลัมน์ ชนิดข้อมูล สูตร ที่มา และชีตเดิมยังอยู่ ยืนยันการคำนวณใน engine ที่ใช้งานได้ หรือระบุชัดว่าตรวจได้เพียงสูตรกับยอดคำนวณอิสระ ปรับความกว้าง การตัดบรรทัด และ freeze header ให้อ่านได้ โดยรักษารูปแบบบริษัทเป็นหลัก
