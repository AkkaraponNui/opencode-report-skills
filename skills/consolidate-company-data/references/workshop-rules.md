# กติกาสำหรับ workshop รวมยอดขายสามแหล่ง

อ่านเมื่อผู้ใช้ระบุว่าใช้โจทย์ workshop นี้เท่านั้น ก่อนใช้ให้ตรวจว่ามี `input/01-store.csv`, `input/02-website.csv`, `input/03-agent.csv` และ `company-template.xlsx` ที่มี Sales, Dictionary, Products หากโครงสร้างไม่ตรง ให้รายงานความต่างและยึดคำสั่งปัจจุบัน อย่าเปลี่ยนไฟล์ให้ตรงตัวอย่างโดยเดา

## หน่วยรายการและคอลัมน์

หนึ่งแถวเป็นหนึ่งรายการสินค้า คีย์ร่วมคือ **เลขคำสั่งซื้อ + ลำดับรายการ** เลขคำสั่งซื้อมีความหมายร่วมกันทุกไฟล์ ไม่เพิ่มช่องทางหรือชื่อไฟล์เข้าในคีย์

| ปลายทาง Sales | 01-store.csv | 02-website.csv | 03-agent.csv |
| --- | --- | --- | --- |
| วันที่ | วันที่ขาย | order_date | SaleDate |
| เลขคำสั่งซื้อ | เลขที่ออเดอร์ | order_id | OrderNo |
| ลำดับรายการ | รายการที่ | line_no | ItemNo |
| ช่องทาง | ช่องทางขาย | sales_channel | Origin |
| ลูกค้า | ชื่อลูกค้า | customer | Client Name |
| รหัสสินค้า | รหัสสินค้า | sku | ItemCode |
| ชื่อสินค้ามาตรฐาน | อ้างอิง Products ผ่านรหัสสินค้า | อ้างอิง Products ผ่านรหัสสินค้า | อ้างอิง Products ผ่านรหัสสินค้า |
| จำนวน | จำนวนชิ้น | qty | Units |
| ราคาต่อหน่วย | ราคา_บาท | unit_price | PriceTHB |
| ยอดขาย | สูตรจำนวน × ราคา | สูตรจำนวน × ราคา | สูตรจำนวน × ราคา |
| ไฟล์ต้นทาง | สร้างจากชื่อไฟล์ | สร้างจากชื่อไฟล์ | สร้างจากชื่อไฟล์ |
| แถวต้นทาง | สร้างจากเลขแถว CSV | สร้างจากเลขแถว CSV | สร้างจากเลขแถว CSV |

คอลัมน์ชื่อสินค้าดิบคือ ชื่อสินค้า, product_name, Description ตามลำดับ เก็บไว้เป็นหลักฐาน แต่ชื่อมาตรฐานต้องมาจาก Products โดยรหัสสินค้า ห้ามใช้ชื่อสินค้าเดารหัสที่ขาด

## การแปลงที่อนุญาต

- 01-store.csv: วันที่ `dd/mm/yyyy` ค.ศ.; 02-website.csv: `yyyy-mm-dd` ค.ศ.; 03-agent.csv: `dd-mm-yyyy` พ.ศ. ให้ลบ 543 เฉพาะปีของแหล่งนี้ บันทึกปลายทางเป็นวันที่ Excel แสดง `yyyy-mm-dd`
- ช่องทาง: หน้าร้าน = POS = Shop; เว็บไซต์ = WEB = Online; ตัวแทนขาย = DEALER = Agent ใช้ค่าคอลัมน์ ไม่ใช่ชื่อไฟล์
- ตัดช่องว่างหัวท้ายลูกค้า เลขคำสั่งซื้อ และรหัสสินค้า เปลี่ยนรหัสสินค้าเป็นตัวใหญ่ แต่คงเลขคำสั่งซื้อเป็นข้อความ แปลงลำดับรายการเป็นจำนวนเต็มบวก
- ตัดคำว่า `ชิ้น` จากจำนวน และ `THB` กับ comma คั่นหลักพันจากราคา ตัวเลขในโจทย์นี้ใช้จุดเป็นทศนิยม จำนวนต้องเป็นจำนวนเต็มบวก ราคาต้องมากกว่าศูนย์ สกุลบาท ไม่มีการแปลงหน่วยเพิ่ม
- ราคาจาก Products เป็นราคาอ้างอิง ไม่ใช้แทนราคาขายที่ขัดแย้งกัน ยอดขายใช้ `ROUND(จำนวน*ราคาต่อหน่วย,2)` ไม่มีภาษีหรือส่วนลดเพิ่ม

## การรวมและพักข้อมูล

ทุกช่องของ Sales ต้องครบในรายการที่ยืนยันได้ โดยชื่อมาตรฐาน ยอดขาย และพิกัดต้นทางสร้างตามกฎข้างต้น

คีย์เดียวกันที่วันที่ ช่องทาง ลูกค้า รหัสสินค้า จำนวน และราคาตรงกันหลังแปลง ให้รวมเป็นรายการเดียว ชื่อสินค้าเดิมต่างภาษาได้ บันทึกไฟล์และแถวต้นทางทั้งหมดคั่นด้วย ` | ` และจับคู่ตามลำดับ

หากค่าหลักต่างกันหรือขาด ให้พักทุกแถวของคีย์นั้น ไม่มีแหล่งชนะอัตโนมัติ ช่องว่างไม่ใช่ศูนย์ ค่าที่ยังไม่มีคนยืนยันต้องเว้นว่างในช่องคำตอบยืนยัน ผู้รับผิดชอบที่ควรติดต่อระบุเป็นบทบาท เช่น ผู้บันทึกหรือเจ้าของคำสั่งซื้อ ไม่แต่งชื่อบุคคล

CSV ใช้ UTF-8 with BOM และ comma โดยค่าเงินที่มี comma อยู่ใน quoted field พิกัดแถวรวม header เป็นแถว 1 และข้อมูลเริ่มที่แถว 2 ตรวจจำนวนและยอดจากไฟล์ที่ได้รับในแต่ละครั้ง ไม่ใช้ค่าคงที่จากเฉลย
